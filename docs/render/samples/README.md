### Полная книга оружия — единая каноническая сборка RU и EN

Печатные издания: **176 страниц в RU и 180 в EN**, по 144 карточки и
печатное оглавление на стр. 4–5. В EN наличие хотя бы одного варианта,
который встречается у одного оружия главы, означает, что расписываются
**все** моды этого оружия (например, у Laser Musket). Если полная таблица
не помещается на карточке, она целиком уходит под название оружия в раздел
**Specific Modifications** (например, у Pipe Gun). Без уникальных вариантов
на карточке остаётся компактная таблица по слотам. Для неё параметры
находятся в начале главы: общие строки совпадают у четырёх и более видов
оружия, варианты с двумя или тремя совпадениями расписаны под названием
оружия. Двух таблиц модов на одной карточке нет.
Вёрстка и оглавление RU не изменены.

Для четырёх карточек сравнение и решения записаны в
[отчёте сверки](../../weapon-mod-source-audit.md). Это не полная сверка всех
модификаций справочника. В английском разделе **Weapon Qualities** названия
без подтверждённого правила сопровождаются короткой пометкой **Needs
clarification**. Для **Re-roll Hit Location** и **Bayonet** использованы
таблицы модификаций исходного PDF (стр. 12, 62 и 68).

Чтобы попробовать локальную сборку, не заменяя опубликованные PDF,
используйте `docs/render/out/`: это рабочая папка, которая не отслеживается Git.

```bash
python3 tools/build_weapon_catalogs.py --out-dir docs/render/out/catalogs
python3 tools/build_weapon_catalogs.py --check --out-dir docs/render/out/catalogs
```

Для публикации обеих версий **не запускайте** отдельно извлечение artwork,
русский/английский сборщик или rasterizer. Нужны только Python-зависимости из
`tools/requirements-pdf.txt` (однократно: `python3 -m pip install -r tools/requirements-pdf.txt`,
если их ещё нет); затем из корня репозитория достаточно одной команды:

```bash
python3 tools/build_weapon_catalogs.py
```

`tools/build_weapon_catalogs.py` — единственная каноническая точка сборки
пары. Он принимает только утверждённый `Справочник оружия.pdf`: до любой
записи SHA-256 сравнивается с
`48c85e12c5eca695e0c4a4fc3a8bf9276d4fb1d1715b6a62f4b0f9c26ffdbd35`.
Поэтому другой экспорт Publisher нельзя незаметно смешать с прежними
результатами.

Команда последовательно выполняет весь релизный контракт в отдельной
временной рабочей папке:

1. заново извлекает из этого PDF ровно 81 PNG asset и строгий
   `artwork-manifest.json`; его утверждённый SHA-256 и все source/placement
   данные проверяются;
2. собирает русскую 176-страничную книгу и её coverage audit, записывает
   диагностический отчёт в `docs/render/out/book-weapon-catalog-report.md` и
   сохраняет исходную обложку Publisher с прозрачностью и слоями;
3. собирает английскую 180-страничную книгу с её локализованной векторной
   обложкой и coverage audit. Меняются только надписи и их тени; новые
   фоновые заливки не добавляются. Для нижней строки использован Anton
   (SIL Open Font License, см. `assets/fonts/Anton-OFL.txt`);
4. создаёт обе mobile-версии из уже собранных canonical PDF: по одному
   непрозрачному RGB JPEG 200 DPI, quality 85 на страницу; для English
   передаётся `metadata-locale en`;
5. проверяет 144 общих карточки, exact-ID artwork coverage (77 replayed,
   6 `manifest-page-without-exported-artwork`, 61 `no-manifest-page`),
   совпадение печатного оглавления и PDF-закладок в обеих книгах,
   обложки RU/EN и raster-only структуру
   обоих mobile PDF. Только после этого заменяет все шесть public artifacts.

То есть русская и английская публикации не могут обновиться по отдельности.
Обе сохраняют подтверждённый inventory: `Unarmed Attack` / «Рукопашная
атака» и `Assaultron Head Laser` / «Головной лазер Штурмотрона» остаются
самостоятельными карточками; `Assaultron Head` / «Голова ассаултрона» и
`Straight Razor` / «Опасная бритва» исключены. `Institute Laser` / «Лазерный
пистолет института» остаётся пустым при отсутствии exact-ID Publisher layer;
арт обычного лазерного пистолета для него не заимствуется.

Для Gauss Rifle / «Карабин Гаусса», Light Machine Gun / «Лёгкий пулемёт» и
Pump-Action Shotgun / «Помповый дробовик» обе книги публикуют только
каноническую `mod_recoil_compensating_stock`. В русской книге она печатается
как «Ложа с компенсатором отдачи» с `+1` к скорости стрельбы, добавлением
«Двуручное» и удалением «Неточное». Дублирующая
`mod_recoil_compensating`, её увеличение дистанции и «Вплотную» не
публикуются; исходные записи Companion при этом не меняются.

В `docs/render/samples/` команда публикует одновременно:

- `book-weapon-catalog.pdf` и
  `book-weapon-catalog-artwork-coverage.json`;
- `book-weapon-catalog-mobile-raster.pdf`;
- `book-weapon-catalog-en.pdf` и
  `book-weapon-catalog-en-artwork-coverage.json`;
- `book-weapon-catalog-en-mobile-raster.pdf`.

Временные PNG/manifest не публикуются и не нужно заранее создавать
`docs/render/pdf-extract/`: launcher воспроизводит их сам для обеих локалей.
Если нужно только проверить уже опубликованный набор без пересборки, используйте
`python3 tools/build_weapon_catalogs.py --check`.

Низкоуровневые `extract_pdf_images.py`, `build_weapon_catalog.py`,
`build_weapon_catalog_en.py` и `rasterize_pdf.py` остаются тестируемыми
составляющими launcher и пригодны для локальной диагностики, но не являются
инструкцией для выпуска одной локали.

## Книга брони

| Файл | Что это |
|---|---|
| `armor-leather-book.pdf` | референс пользователя: кожаная броня, 2 страницы (снята геометрия) |
| `armor-book.pdf` | русская книга, собранная `tools/armorbook2pdf.py`: 62 страницы — общий каталог модов обычной брони (1 страница), броня (6 сетов), общий каталог модов силовой брони (2 страницы), силовая броня (6 наборов и 5 страниц уникальных модификаций), общий каталог модов одежды (1 страница), одежда (32 отдельных предмета) |
| `armor-book-en.pdf` | та же 62-страничная книга на английском: локализованы названия предметов, модов и эффектов, заголовки, характеристики, требования, каталоги и вводный текст кожаной брони |

У обычной брони первая страница сета содержит «Стандартный комплект» и
«Поддерживаемые модификации», а вторая — варианты
(укреплённая/тяжёлая) и уникальные модификации. В стандартном комплекте
строка делится пополам: левая половина зарезервирована для иллюстрации,
правая содержит вложенные таблицы четырёх деталей. Они разнесены пустым
пространством по обеим осям: 14 pt между столбцами и 45 pt между рядами.
Перед наборами расположен общий справочник стандартных модов: эффект,
деталь, вес, цена, перк и навык, поэтому назначение «Мягкой» и других
подкладок не теряется в коротком списке совместимости. Перед моделями
силовой брони расположен общий
справочник: он один раз объясняет эффект, деталь, вес, цену, перк и навык
систем и обшивок. На странице продолжения систем обшивка идёт сразу следом
в той же секции.
На первой странице конкретной модели остаётся короткий список её общих
модификаций. На второй показываются только уникальные улучшения шлема,
нагрудника, наруча и поножа с полными характеристиками; исключительные
система рейдеров и обшивка X-01 там же получают подробную таблицу эффекта.
Каркас не получает вторую страницу: в исходных данных для него нет модов.
Окраски не показаны, потому что источник данных подтверждает только
системы, обшивку и улучшения. Перед предметами одежды расположен общий
справочник тканевых основ и подкладок: в нём у каждого Mk баллистического
плетения явно показаны бонусы к ФИЗ. и ЭНРГ. СУ, вес, цена, перк и навык.
Одежда развёрстана по одному предмету на страницу; блок модов печатается
только для предметов, для которых совместимость известна.

```bash
# Русская версия (локаль по умолчанию)
python3 tools/armorbook2pdf.py --out docs/render/samples/armor-book.pdf

# Английская версия
python3 tools/armorbook2pdf.py --locale en-EN --out docs/render/samples/armor-book-en.pdf
```

Источником совместимости модов силовой брони и одежды служит
`handylinux/Fallout-2d20-helper`. После обновления его данных пересоберите
соответствующие JSON-файлы, затем книгу:

```bash
python3 tools/powerarmor_mods_from_helper.py /путь/к/Fallout-2d20-helper
python3 tools/clothes_mods_from_helper.py /путь/к/Fallout-2d20-helper
python3 tools/armorbook2pdf.py --out docs/render/samples/armor-book.pdf
```

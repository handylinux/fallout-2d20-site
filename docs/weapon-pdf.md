# PDF-справочник оружия: шаблон A4

Одна единица оружия — одна страница A4. Макет снят с PDF, собранного в
Publisher (`docs/render/Справочник оружия-pinkibook-018.pdf`, страница 18,
«Боевой карабин»), и воспроизводится скриптом `tools/weapon2pdf.py`.

```
Companion JSON  →  tools/weapons2cards.py  →  карточка JSON
                                            →  tools/weapon2pdf.py  →  PDF A4
```

Карточка — это уже готовые к печати данные (заголовок, статы, описание,
строки модификаций). Тот же JSON потом будет питать и веб-каталог.

## Шрифты

В оригинале — **Calibri** и **Calibri Bold** (подтверждено `pdffonts`).
В генераторе — **Carlito** (`assets/fonts/`, лицензия OFL): метрически
совместимый свободный клон Calibri, поэтому переносы и ширина строк
совпадают с оригиналом. Кегли:

* заголовок 21.98 pt Bold, капс;
* подзаголовок 14.04 pt;
* шапка таблицы 9.96 pt Bold, «СКОРОСТЬ СТРЕЛЬБЫ» — 9 pt в две строки;
* ячейки статов 9.96 pt;
* описание 12 pt, интерлиньяж 17.4 pt, выключка по ширине;
* заголовок «ПОДДЕРЖИВАЕМЫЕ МОДИФИКАЦИИ» 18 pt Bold;
* моды 9 pt, интерлиньяж 13.08 pt;
* метки слотов 9.96 pt Bold, белые.

## Правила таблицы модификаций

* Слотов максимум 6 колонок; в строке — до 6 модов.
* Если у категории больше 6 модов, она занимает несколько строк по 6 ячеек;
  чёрная метка слота растягивается на весь блок и центрируется по вертикали.
* Цвет блока чередуется: бежевый → оранжевый → бежевый …
* Пустые ячейки остаются в сетке и заливаются цветом блока.
* Таблица растягивается до нижнего поля: свободное место делится поровну
  между строками, но не больше ~70 pt на строку (высота строки до ~91 pt).
  Если строк совсем мало, таблица заканчивается выше.
* Если модов нет вообще — вместо таблицы выводится
  «НЕТ ПОДДЕРЖИВАЕМЫХ МОДИФИКАЦИЙ».
* Длинные значения в таблице статов (например, «Энергетический» или
  «Крио-элемент») автоматически уменьшаются до 2 строк, чтобы не вылезать
  в соседнюю ячейку.
* То же и для модов: если одно слово шире ячейки (например,
  «Квантовая гиростабилизирующая линза»), кегль этой ячейки уменьшается
  с 9 pt до 6.5 pt, переносы остаются по словам.
* Эффекты печатаются через запятую в том порядке, что в данных; значение
  (например, `effect_piercing_x` с `value: 2`) выводится как
  «Проникающий 2». Три эффекта в узкой ячейке («Порочный, Разрушающий,
  Радиоактивный» у «Толстяка») уменьшаются до 2 строк.
* Набор категорий у каждого оружия свой: берутся только те слоты, что есть
  в `weapon_mod_slots.json`. Порядок: РЕСИВЕР, СТВОЛ, КОНДЕНСАТОР, СОПЛО,
  РУКОЯТЬ, ЛОЖА, МАГАЗИН, ПРИЦЕЛ, ДУЛО, затем остальные по алфавиту (как в
  присланных страницах). Моды внутри категории — в порядке данных Companion.
* Русские метки слотов лежат в Companion
  (`i18n/ru-RU/screens-weaponsAndArmor.json` → `weapon.modSlots` — копия
  `screens/weaponsAndArmor/screen.json` из компаньона,
  21 ключ: `receiver`, `barrel`, `sight`, `muzzle`, `stock`, `grip`,
  `magazine`, `capacitor`, `canister`, `concentrate`, `container`, `dishe`,
  `fuel`, `launcher`, `nozzle`, `tank`, `frame`, `winch`, `chamber`,
  `unique`, `other`). Для семи классических слотов оставлены книжные
  написания (ДУЛО, ЛОЖА, …), остальные печатаются капсом из перевода
  (КОНДЕНСАТОР, СОПЛО, …).

## Нумерация

Номер страницы стоит в наружном поле: чётные страницы — слева, нечётные —
справа (в PDF страница 18 — слева, на скриншоте страница 15 — справа).

## Что делать с длинным описанием

Область описания — примерно 4 строки при 12 pt. Если текст не влезает,
кегль уменьшается до 10 pt (интерлиньяж — пропорционально). Если и этого
мало, текст обрезается по границе слова с «…» и выводится предупреждение:
лучше поправить текст руками, чем молча получить наложение на таблицу.

## Данные Companion

Что уже есть в `data/companion/`:

| Поле PDF | Источник |
|---|---|
| Название | `ru-RU/.../weapons/weapons.json` → `name` |
| Вес / Цена / Редкость | `weapons.json` → `weight`, `cost`, `rarity` |
| ПАТРОН | `ammoId` → `ammo/ammo_types.json` |
| ТИП УРОНА | `damageType` → русская подпись |
| УРОН | `damage` + иконка `assets/pdf/damage-icon.png` |
| СКОРОСТЬ СТРЕЛЬБЫ | `fireRate` |
| ДИСТАНЦИЯ | `range` → `rangeName`; у ближнего боя дистанции нет |
| ЭФФЕКТЫ | `effects[]` → `ru-RU/data/system/damageEffects.json` |
| КАЧЕСТВА | `qualities[]` → `ru-RU/data/system/qualities.json` |
| Моды | `weapon_mod_slots.json` + `weapon_mods.json` (RU) |
| Описание | **нет русского** (см. ниже) |
| Картинка | **нет в данных** |

Русские названия эффектов лежат в `damageEffects.json` (10 записей,
`effect_vicious` → «Порочный»), качества — в `qualities.json`
(`quality_close_quarters` → «Вплотную»), типы урона — в
`ru-RU/screens/addItemModal.json` (`physical` → «Физический» и т. д.).

### Чего не хватает

1. **Описания.** В RU-файле 130 из 146 `flavour` — английские, 5 пустых.
   Пока это устраивает: генератор берёт `flavour` как есть. Когда появятся
   русские тексты, их достаточно положить в
   `data/weapons/descriptions.ru.json` (`id → текст`) — скрипт подхватит
   автоматически.
2. **Картинки.** В Companion их нет. Ожидаемый путь —
   `assets/pdf/weapons/<slug>.png`, PNG с прозрачностью. Для примеров
   подставляется `assets/pdf/weapons/combat-rifle.png` (заглушка).
3. **Иконка урона.** Та же `CD.png`, что на сайте; в PDF она 41 × 41 px
   (для 20 pt при 300 dpi хотелось бы ~83 px, но пока печатается как есть).
4. **Слоты роботов.** Роботов пока не трогаем: в книге только оружие.
   Метки для всех 21 слота уже подтягиваются из
   `screens/weaponsAndArmor/screen.json`, поэтому энергооружие
   («Конденсатор», «Сопло») и прочие типы собираются без правок кода.
5. **Типы урона.** Русские подписи уже есть в Companion
   (`addItemModal.json`): Физический, Энергетический, Радиационный, Особый,
   Яд. Для составного `["energy","physical"]` склеиваем через «и».

## Отличия от Publisher-оригинала

* Заголовок, линейка и подзаголовок центрированы по полю контента; в PDF
  они смещены вправо на ~13–18 pt (ручная погрешность вёрстки).
* Картинка растягивается по рамке (как в PDF). Искажение пропорций —
  намеренное: так все стволы занимают одинаковое место на странице.
* Высота строк модов считается по содержимому: строка выше, если название
  мода занимает 2–3 строки. Свободное место до нижнего поля делится между
  строками (но не больше 70 pt на строку).

## Запуск

```bash
python3 -m pip install -r tools/requirements-pdf.txt
python3 tools/weapon2pdf.py data/weapons/cards/combat-rifle.json \
    --out docs/render/out/combat-rifle.pdf
```

Проверка:

```bash
python3 -m unittest discover -s tools -v
```

`docs/render/out/` — черновики, в git не попадают. Готовые образцы лежат в
`docs/render/samples/` (там же README со списком страниц).

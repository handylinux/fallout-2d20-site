# Сверка сайта, исходного PDF и Companion

Сводный список решений и нерешённых расхождений: [weapon-discrepancies.md](weapon-discrepancies.md).

Начальный этап ручной сверки: четыре страницы оружия, не весь справочник. Источник сайта — отдельная версия данных, а не доказательство официальности; одинаковые цифры не означают, что все остальные поля проверены. Для исходного PDF указаны физические страницы. Companion — рабочая копия `data/weapon-book/companion/`.

## 10-мм пистолет

[Страница сайта](https://www.fallout-2d20.ru/oruzhie/strelkovoe-oruzhie/10-mm-pistolet); PDF стр. 14, общая таблица стр. 10–12.

- Основные характеристики, проверенные в трёх источниках: патрон 10-мм, физический урон 4 БК, скорострельность 2, близкая дистанция, вес 4, цена 50, редкость 1. В PDF и на сайте указаны качества «Вплотную» и «Надёжное», как в Companion.
- «Большой магазин»: сайт и PDF указывают перк «Фанатик оружия 2», Companion — `Gun Nut 1`. Остальные показанные параметры: +1 скорострельность, «Ненадёжное», вес +1, цена −3. **Пока без изменения сборки**, общая применимость требует проверки.
- На странице сайта в списке ресиверов показаны 6 позиций; в PDF и списке слотов Companion — 13. Отсутствие позиции на сайте само по себе не доказывает, что она не поддерживается. Заголовки двух строк сайта «Укреплённый» и «Усиленный» переставлены относительно содержимого их таблиц. Нужна ручная сверка, не автоматическое сопоставление по заголовку.

[Страница сайта](https://www.fallout-2d20.ru/oruzhie/strelkovoe-oruzhie/abordazhnyj-pistolet); PDF стр. 51. Сверка четырёх модов, скорости стрельбы и решение для карточки — в `docs/weapon-boarding-comparison.md`.

## Лазерный мушкет

[Страница сайта](https://www.fallout-2d20.ru/oruzhie/energooruzhie/lazernyj-mushket); PDF стр. 81 и общая таблица стр. 78–79.

- Сайт указывает боеприпас «Ядерная батарея», PDF — «Энергоячейка», в рабочей копии Companion указан `ammo_energy_cell`. Одинаковость этих русских названий не установлена: в сборке пока оставлено название из PDF.
- PDF перечисляет конденсаторы 3–6 зарядов без их характеристик. Сайт явно описывает расход 3, 4, 5 и 6 зарядов на атаку и бонусы +1, +2, +3 и +4 БК. Companion содержит эти бонусы и `quality_crank_x` со значениями 1–4; прежнее отображение «Ствол X» не объясняло расход. В общую таблицу внесена понятная формулировка расхода с сайта. Вес трёхзарядного на сайте «—», в Companion отсутствует; оставлен прочерк, не ноль.
- Указание о том, что модификации конденсатора увеличивают расход и урон, добавлено в особенность по сайту; особенность в PDF это прямо не упоминает.
- Сайт указывает для длинного ствола с кронштейном вес +2, PDF стр. 78 — +1. Сайт для разделителя луча указывает −1 скорострельность, PDF стр. 79 — тоже −1, а рабочий Companion для `mod_beam_splitter` — +1. Это **не исправлено автоматически**; требуется отдельная сверка общих модов и их применимости.
- Штык указан в списке PDF на странице оружия, но не в модах на странице сайта; он отсутствует в исходных общих таблицах энергооружия. Оставлен для проверки.

## Головной лазер штурмотрона

[Страница сайта](https://www.fallout-2d20.ru/oruzhie/energooruzhie/golovnoj-lazer-shturmotrona); PDF стр. 94.

- На сайте боеприпас назван «Ядерная батарея», в PDF — «Энергоячейка», в Companion для `weapon_assaultron_head_laser` — `ammo_fusion_core`. В карточке пока сохранена «Энергоячейка» по PDF; сопоставление названий необходимо проверить.
- PDF перечисляет MK III–VI без характеристик. Сайт явно указывает расход 3–6 зарядов и бонус урона +1…+4 БК. Companion имеет соответствующие бонусы и `quality_crank_x` 3–6. В карточке расход теперь изложен по сайту, вместо непонятного «Ствол X».
- Перк для MK III: сайт — «Эксперт по робототехнике», Companion — прочерк; MK IV: сайт — этот перк и «Наука! 1», Companion — прочерк; MK V: сайт — эксперт и «Наука! 2», Companion — «Наука! 1»; MK VI: сайт — эксперт и «Наука! 3», Companion — «Наука! 1». В карточке использован сайт, расхождение остаётся открытым для проверки. Вес MK III на сайте — прочерк, Companion — 0; в карточке сохранён прочерк. Стоимость +4/+8/+12/+16 совпадает с Companion.

## Гатлинг-лазер

[Страница сайта](https://www.fallout-2d20.ru/oruzhie/tyazhjoloe-oruzhie/gatling-lazer); PDF стр. 60.

- Основные характеристики сайта и PDF: 3 БК, скорострельность 6, средняя дистанция, вес 19, цена 804, редкость 3; эффекты «Проникающий 1» и «Очередь». В Companion эффекты включают «Проникающий» без числового значения. Карточка пока не исправлена.
- Названия и характеристики четырёх конденсаторов расходятся: например, сайт для тюнера бета-волн указывает «Устойчивый», вес +1, цена +57, без перка; PDF для одноимённого тюнера — «Порочный», +1, +19, «Наука! 3»; Companion — «Устойчивый», вес не указан, +30, без перка. При этом у сайта и PDF названия нескольких строк сопоставлены с разными эффектами и ценами. Не переставлять строки автоматически.
- Фотонная мешалка: сайт +3 вес, +32 цена, «Наука! 3»; PDF +3, +132, «Наука! 3»; Companion +1, +35, «Наука! 2». Коллиматор: сайт +1, +169, «Наука! 4»; PDF +3, +28, без перка; Companion вес не указан, +14, без перка и иной эффект. Параметры на странице оружия пока из PDF, выбор источника требует решения.

## Порядок дальнейшей работы

Сверять небольшими партиями: базовые характеристики, особые правила, наличие и параметры модов. Записывать прямую ссылку, страницу PDF и отличия по каждому источнику. Значения с сайта, использованные для конденсаторов, вынесены отдельно в `data/weapons/energy-mod-overrides.json`; оригинальный Companion не меняется. Остальные страницы и моды пока не считаются сверенными.

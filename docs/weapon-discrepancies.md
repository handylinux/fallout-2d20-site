# Расхождения в данных оружия — список на проверку

Это рабочий список, **не полный аудит**. Решения пользователя отмечены как согласованные; прежние значения сохранены в строках для истории. Он пока составлен по первым четырём страницам оружия и ранней сверке ресиверов. Книга и сайт могут содержать данные из разных дополнений или более старых изданий; Companion и его справочные файлы, созданные в рамках общего проекта, тоже опираются на книги и могут включать исправления эрраты. Проверяем происхождение каждого варианта и сохраняем различия для решения.

**Правило работы:** сохранять значения всех источников и страницу / версию, не объявлять один источник автоматически правильным, не объединять похожие моды без проверки применимости. Исправление считать подтверждённым эрратой только после проверки оригинального документа с датой и страницей. Вариант в PDF указан как текущий для просмотра, а не как окончательный выбор пользователя. Прочерк, ноль и отсутствие поля различаются.

## Источники и версия

- **Книга** — локальный `Справочник оружия.pdf`, номера ниже — физические страницы PDF. Это подготовленный пользователем и друзьями справочник, включающий материалы из разных книг, не обязательно один тираж правил.
- **Сайт** — страницы fallout-2d20.ru, указанные в [сверке с сайтом](weapon-site-comparison.md); данные тоже могли меняться и представлять отдельные варианты.
- **Companion** — наша рабочая копия `data/weapon-book/companion/`; её значения не считать доказанной официальной эрратой. Версия источника именно этой локальной копии не зафиксирована — требуется установить отдельно.
- **Референсы Companion** — на момент просмотра GitHub зафиксирован коммит [`2e66c7dc7c07d1fe1e62b1585e8764f453417193`](https://github.com/rpg-companios/Fallout-2d20-companion/tree/2e66c7dc7c07d1fe1e62b1585e8764f453417193/docs/reference-data). Его [README](https://github.com/rpg-companios/Fallout-2d20-companion/blob/2e66c7dc7c07d1fe1e62b1585e8764f453417193/docs/reference-data/README.md) описывает данные сторонних проектов Pip-Boy, Lone Star, Pip-Boy 3000 и focharactersheet; их данные также основаны на книгах и учитываются как референсы общего проекта; конкретную книгу, редакцию и возможную эррату нужно устанавливать по каждой записи. Их [weapon audit](https://github.com/rpg-companios/Fallout-2d20-companion/blob/2e66c7dc7c07d1fe1e62b1585e8764f453417193/docs/reference-data/WEAPON-AUDIT.md) и [открытые вопросы по модам](https://github.com/rpg-companios/Fallout-2d20-companion/blob/2e66c7dc7c07d1fe1e62b1585e8764f453417193/docs/reference-data/weapon-mods-open-questions.md) — исторические отчёты, не гарантия состояния нашей копии. Референс из GitHub может быть новее локальных данных Companion.
- **Эррата** — требуется оригинальный документ и точная версия. Пока использован только вторичный пересказ, отдельно отмеченный ниже; его нельзя считать проверкой оригинала.

## Уже внесённые предварительные выборы

Для проверки пользователем перечислены не только будущие расхождения: в предыдущих сборках уже использованы параметры сайта для абордажного пистолета и конденсаторов штурмотрона. Эти решения **не являются подтверждением эрраты** и остаются открытыми. Поправки хранятся отдельно от оригинала Companion в `data/weapons/small-guns-mod-overrides.json`, `data/weapons/energy-mod-overrides.json` и соответствующих файлах параметров оружия.

## Как расширять список

Для каждой следующей партии фиксировать ID оружия и мода, поле и значения всех проверенных источников, книгу/страницу и редакцию, прямую ссылку на сайт или точный коммит данных, факт или отсутствие проверки эрраты, текущий вариант в PDF и статус решения. Отсутствие данных, расхождение названий и несовпадение применимости отмечать отдельно от несовпадения чисел. Не менять каталог автоматически по результатам сравнения.

## Ближний бой: первые шесть страниц

Предварительная сверка оригинальных страниц 96–101 и рабочих данных Companion,
без утверждения об источнике эрраты: подробности в [отчёте](weapon-melee-report.md).
Боевой нож: урон 4 в оригинале, 3 в Companion. Потрошитель: «Проникающий 1»
и два мода в оригинале против «Порочного» и четырёх модов в Companion;
оригинальное описание повторяет боевой нож. Шиш-кебаб: вес/цена/редкость
1/20/0 в оригинале против 3/200/3 в Companion. Уровень «Проникающего»
в оригинале равен 1, а в нескольких карточках Companion не указан. У меча
в Companion добавлен электрошокер. Пока использованы значения Companion,
вопросы остаются открытыми для проверки по книгам, сайту и эррате.

## Каталог: записи без подтверждённых модов

В рабочих данных у плазменной мины указан мод `mod_heavy_barrel` (тяжёлый
ствол), причём обе связи Companion считают его применимым. Для мины это
сомнительно; мод временно не включён в карточку, необходима проверка источника.
У ряда предметов отсутствует список модификаций без явного признака их
отсутствия; они помечены как требующие проверки, а не как оружие без модов.
Состав включённых и исключённых записей — в `weapon-catalog-report.md`.

## Применимость и категории модов ближнего боя

Сайт показывает модификации и для рукопашного оружия, но одинаковые ID
Companion дают неверные параметры для разных предметов (в частности кувалды,
боксерской перчатки и кастетов). Проверенные поправки на отдельное оружие и
ссылки на источники — в [сверке](weapon-melee-site-review.md). Различия с
Companion сохранены, происхождение из эрраты ещё не установлено.

## Машинная сверка числовых параметров

Начат [аудит по голосам](weapon-source-numeric-audit.md): вес, цена и
редкость оригинала; пять числовых полей доступных референсов и восемь вручную
проверенных страниц сайта. Зафиксированные решения пользователя сохраняются,
автоматические изменения не вносятся до полного сбора источников. Это ещё не
сверка эффектов, категорий, модов и эрраты. Данные Pip-Boy 3000 по весу
отложены из-за систематического различия масштаба.

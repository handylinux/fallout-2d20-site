## Уточнения пользователя

- `weapon_unarmed_attack` и `unarmed_human` — одна и та же безоружная атака / кулаки; не печатать два самостоятельных предмета. Выбор основного ID и сохранение ссылки на второй ID нужно решить при сборке.
- `weapon_straight_razor` (опасная бритва) — ссылка на другое оружие, не самостоятельный предмет. Цель ссылки нужно установить по данным, не угадывать.
- Использовать название «штурмотрон», не «ассаултрон». Сопоставление `weapon_assaultron_head` с уже имеющимся головным лазером пока не подтверждено.
- В энергоразделе на разных страницах используются либо названия модификаций, либо их характеристики; выбирать по образцу конкретной страницы.
- Английские описания допустимы. Отсутствующие изображения можно добавить позже.

## Дальше

- Сверить для каждой страницы представление модов: названия, характеристики или отсутствие модов. Не назначать единое правило всему энергоразделу.
